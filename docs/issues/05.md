# Implementar pelo menos 3 cenários Playwright

## Objetivo

Configurar Playwright com TypeScript e automatizar CT01, CT09 e CT03 na UI; complementar API se necessário.

## Dependências

02; usar resultados de 03 para orientar. Identificadores do backlog, não números de issues do GitHub.

## Critérios de aceite

- [ ] Pelo menos 3 cenários reais, sem mocks do comportamento avaliado.
- [ ] testes isolados.
- [ ] asserts de valores e mensagens.
- [ ] seletores estáveis.
- [ ] Node e dependências definidos com lockfile.
- [ ] execução inicial com 1 worker.
- [ ] relatório HTML e trace/screenshot em falha.
- [ ] README com instalação e comandos verificados.
- [ ] resultados reais registrados, inclusive falhas de produto.

## Entrega

Commit/PR com os arquivos e registros correspondentes. Vincular os cenários e as evidências aplicáveis.
